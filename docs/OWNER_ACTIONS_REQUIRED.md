# Owner Actions Required

This document isolates all tasks that require account access, legal confirmations, console credentials, or human-in-the-loop actions.

---

## High Priority / Immediate Blocking Actions

### 1. Google Play Console App Creation & Developer Identity
- [ ] Ensure Google Play Developer account identity verification & registration fee payment are completed.
- [ ] Create application in Play Console:
  - App name: **CVScan - AI Resume & ATS Coach**
  - Default language: English (United States) or English (Australia)
  - App or Game: App
  - Free or Paid: Free (with In-App Purchases)

### 2. Google Cloud Service Account & Play Billing Credentials
- [ ] In Google Cloud Console, create a Service Account with access to the Google Play Developer API.
- [ ] In Google Play Console -> **API access**, invite/link this service account and grant permissions:
  - `View app information`
  - `View financial data and orders`
  - `Manage orders and subscriptions`
- [ ] Download the Service Account JSON key.
- [ ] Add the JSON string to production environment variables (e.g. Vercel):
  - Variable: `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON`
  - Variable: `GOOGLE_PLAY_PACKAGE_NAME` = `com.cvscan.app`
  - Variable: `GOOGLE_PLAY_WEBHOOK_TOKEN` = `<strong_random_token>`

### 3. Create In-App Products in Google Play Console
- [ ] Navigate to **Monetize > In-app products**.
- [ ] Add the following 3 consumable products:
  - ID: `starter` (Price: $4.99)
  - ID: `popular` (Price: $9.99)
  - ID: `pro` (Price: $15.99)
- [ ] Activate all 3 products.

### 4. Play App Signing & Digital Asset Links
- [ ] Under **Setup > App integrity**, activate Google Play App Signing.
- [ ] Copy the SHA-256 fingerprint generated by Google Play App Signing.
- [ ] Replace the placeholder in `app/public/.well-known/assetlinks.json` with this fingerprint.
- [ ] Commit and deploy to Vercel so `https://cvscan.com.au/.well-known/assetlinks.json` serves the valid certificate fingerprint.

### 5. Production Keystore Setup for CI Builds
- [ ] Generate an upload key (`keytool -genkey -v -keystore release-upload.jks ...`).
- [ ] Base64 encode it and set the GitHub Actions secrets:
  - `KEYSTORE_BASE64`
  - `KEYSTORE_PASSWORD`
  - `KEY_ALIAS`
  - `KEY_PASSWORD`
- [ ] Trigger `.github/workflows/android-release.yml` to automatically produce the signed `app-release.aab`.

### 6. Closed Testing Track (12 Testers for 14 Days)
- [ ] In Play Console -> **Testing > Closed testing**, create a closed track.
- [ ] Upload the generated `app-release.aab`.
- [ ] Recruit at least 12 testers with personal Google accounts.
- [ ] Ensure all 12 testers remain opted-in for 14 continuous days to satisfy Google Play's personal developer account requirement.

## Legal & Compliance Confirmations

### 1. Data Protection & AI Terms
- [ ] Verify Data Processing Addendums (DPAs) with AI sub-processors:
  - OpenAI API (Data privacy & zero-retention policy for API calls)
  - Google Gemini API (Ensure prompt data is not used for foundation model training)
  - Supabase (PostgreSQL data residency and encryption at rest)
  - Resend (Transactional emails)

### 2. Data Safety Worksheet Confirmation in Play Console
- Complete Data Safety responses using `docs/PLAY_STORE_METADATA.md`:
  - Personal Info: Name, Email address (Account management, App functionality)
  - Files and docs: Resumes, cover letters (App functionality, ephemeral or stored per user preference)
  - Financial Info: Handled via Google Play Billing (No credit card numbers collected by app)
  - Security practices: Data encrypted in transit (HTTPS / TLS 1.3), user account deletion provided both in-app and via web URL (`https://cvscan.com.au/delete-account`).
